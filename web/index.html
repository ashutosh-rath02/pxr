What this demo establishes

Inspect reproducible decisions and fault transitions. Time advances only when you run a scenario or an action.

This is a simulation. Browser timing does not establish MCU deadlines or physical actuator behavior. PXR’s supervisor requires regular service; an independent hardware watchdog covers a stopped controller.
